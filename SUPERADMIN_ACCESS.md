# 🔧 SuperAdmin Access Guide

## ✅ How to Access SuperAdmin Dashboard

### Production (Deployed Site)
Simply visit the `/superadmin` route on your main site:

```
https://ldoia.com/superadmin
```

Or if using Netlify default URL:
```
https://your-site-name.netlify.app/superadmin
```

### Local Development
When running locally:
```
http://localhost:8080/superadmin
```

---

## ❌ Common Mistake

**DO NOT deploy the `super-admin` folder separately!**

The `super-admin` folder contains old HTML files that are **not used** in the current application. The actual SuperAdmin dashboard is a React component located at:

```
client/superadmin/SuperAdminDashboard.tsx
```

This component is already included in your main application build and accessible via the `/superadmin` route.

### 1. Deploy Main Application to Netlify

### 2. Access SuperAdmin

## 🔍 Troubleshooting

### "SuperAdmin page shows blank/404"

**Solution 1: Check Build Output**
```bash
npm run build
ls -la dist/
```

Make sure `dist/` contains:
- `index.html`
- `assets/` folder with JS and CSS files

**Solution 2: Verify Netlify Settings**
1. Go to Netlify dashboard
2. Site settings → Build & deploy → Build settings
3. Ensure:
   - Build command: `npm run build`
   - Publish directory: `dist`
   - No base directory

**Solution 3: Check Redirects**
Your `netlify.toml` should have:
```toml
[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

This ensures all routes (including `/superadmin`) work correctly with React Router.

### "Getting 404 when refreshing SuperAdmin page"

This means the redirect rule isn't working. Check:
1. `netlify.toml` is in the root folder
2. Redeploy after adding the redirect rule
3. Clear browser cache and try again

### "SuperAdmin loads but shows errors"

Check:
1. **Backend API URL**: Ensure `.env.production` has correct backend URL
2. **CORS**: Backend must allow your frontend domain
3. **Browser Console**: Check for API errors

## 📁 Folder Structure Clarification

```
ldoia-main/
├── client/                    # Frontend React app
│   ├── superadmin/           # SuperAdmin components
│   │   └── SuperAdminDashboard.tsx  ← THE ACTUAL SUPERADMIN
│   ├── App.tsx               # Routing (includes /superadmin route)
│   └── ...
├── super-admin/              # ❌ OLD FOLDER - IGNORE THIS
│   ├── index.html            # Outdated HTML files
│   └── ...                   # Not used in production
├── dist/                     # Build output (after npm run build)
│   ├── index.html
│   └── assets/
└── netlify.toml              # Netlify configuration
```

**Only the `dist/` folder (generated by `npm run build`) should be deployed!**

## 🔐 SuperAdmin Features

The SuperAdmin dashboard at `/superadmin` includes:

1. **Dashboard Stats**
   - Total applications
   - Committee applications
   - Advisory applications
   - Pending/Approved/Rejected counts

2. **Committee Table**
   - View all committee applications
   - Approve/Reject applications
   - View application details

3. **Advisory Table**
   - View all advisory applications
   - Approve/Reject applications
   - View application details

4. **Promotion Images**
   - Upload promotion templates
   - Manage language-specific templates
   - Delete templates
