# LDOIA Gallery Images

This folder contains images for the LDOIA gallery page.

## Image Organization

### Exhibition Photos
Add exhibition photos with names like:
- exhibition-1.jpg
- exhibition-2.jpg
- exhibition-3.jpg
- etc.

### Award Function Photos
Add award ceremony photos with names like:
- award-1.jpg
- award-2.jpg
- award-3.jpg
- etc.

## Image Requirements

- **Format**: JPG, PNG, or WebP
- **Size**: Recommended 1200x800 pixels or similar 3:2 aspect ratio
- **File Size**: Keep under 500KB for web optimization
- **Quality**: High quality but web-optimized

## Naming Convention

Use descriptive names that match the gallery component:
```
exhibition-1.jpg    → Real Estate Expo 2024
exhibition-2.jpg    → Stall Display
exhibition-3.jpg    → Networking Event
exhibition-4.jpg    → Conference Hall
exhibition-5.jpg    → Opening Ceremony
exhibition-6.jpg    → Award Distribution

award-1.jpg         → Excellence Award 2024
award-2.jpg         → Recognition Ceremony
award-3.jpg         → Achievement Awards
award-4.jpg         → Leadership Award
award-5.jpg         → Innovation Award
award-6.jpg         → Community Service
```

## How to Add New Photos

1. Copy your images to this `/public/gallery/` folder
2. Name them according to the convention above
3. Update the titles and descriptions in `/client/pages/Gallery.tsx` if needed

## Fallback Images

If images are not found, the gallery will show placeholder images from Unsplash as fallbacks.

## Tips

- Use consistent lighting and composition
- Include people, activities, and venue shots
- Capture key moments like award presentations, networking, speeches
- Show the scale and professionalism of events
